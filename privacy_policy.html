Core Principle

Every extension we publish is a fully local tool: all computation happens inside your browser, and no input data is ever sent, uploaded, or transmitted to any server.

What We Collect

Nothing. No personal identifiers, device IDs, IPs, or location. No analytics, advertising, or third-party tracking SDKs. No host permissions, no access to the pages you browse.

Data Handling

Text or numbers you enter in the popup are processed in memory for the current tab only and discarded when the popup closes — never stored or uploaded. The extension contains no remotely hosted code (prohibited by Chrome MV3). Password/hash features use the browser's local Web Crypto API; data never leaves the device. Currency conversion uses a bundled static rate table and makes no network requests.

Permissions

Only the minimal permissions required to run (action popup and background service worker) are declared. No permissions to read web pages, access the network, or read user info are requested.

Children

Our tools are not directed to children under 13 and do not knowingly collect their data.
